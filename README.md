# Encoder for 8-bit CPU

Пет-проект: преобразование текстовых инструкций ассемблера в шестнадцатеричный машинный код для учебного 8-битного процессора.

## Предисловие

Этот пет-проект — практическое погружение в то, как текстовые инструкции превращаются в байты, понятные процессору. Вручную писать машинные коды скучно и ошибкоопасно. Энкодер автоматизирует этот шаг и заодно проясняет:

- битовое кодирование команд;
- отображение мнемоник и регистров в числа;
- принцип работы простейшего ассемблера.

## Введение

В реальных микроконтроллерах ассемблер транслируется в машинный код специальной программой — ассемблером. Я сделаю её упрощённую версию для собственной небольшой 8-битной архитектуры.

**Учебный процессор** имеет 4 регистра (A, B, C, D), каждый хранит 8-битное значение (0–255). Он поддерживает 7 инструкций: MOVI, ADD, SUB, MUL, DIV, IN, OUT. Все инструкции кодируются одним байтом, где старший бит (бит 7) определяет тип команды.

Разрабатываемый энкодер будет читать текстовые строки ассемблера и выдавать соответствующий шестнадцатеричный машинный код — именно так, как это делает настоящий ассемблер, но в миниатюре.

## Постановка задачи

Разработать кодировщик (encoder), который преобразует текстовые инструкции ассемблера в шестнадцатеричный машинный код.

## Архитектура процессора

Процессор имеет 4 регистра: A, B, C, D. Каждый регистр хранит 8-битное значение (0-255).

## Система команд

Процессор поддерживает 7 инструкций:

| Инструкция   | Описание                           |
|--------------|------------------------------------|
| MOVI X       | Загрузить число X (0-127) в регистр D |
| ADD Rd, Rs   | Rd = Rd + Rs                       |
| SUB Rd, Rs   | Rd = Rd - Rs                       |
| MUL Rd, Rs   | Rd = Rd * Rs                       |
| DIV Rd, Rs   | Rd = Rd / Rs                       |
| IN Rd        | Ввод числа в регистр Rd             |
| OUT Rs       | Вывод числа из регистра Rs          |

## Кодировка инструкций

Каждая инструкция кодируется одним байтом (8 бит). Старший бит (бит 7) определяет тип команды:

- Бит 7 = 0 -> MOVI (7 бит под immediate)
- Бит 7 = 1 -> остальные команды

### Формат MOVI (бит 7 = 0)

0 IIIIIII

7 бит для числа (0-127)

### Формат остальных команд (бит 7 = 1)

1 OOO RR SS

- OOO - опкод команды (3 бита)
- RR - регистр назначения (2 бита)
- SS - регистр источник (2 бита)

### Таблица опкодов

| Команда       | Опкод |
|---------------|-------|
| ADD Rd, Rs    | 000   |
| SUB Rd, Rs    | 001   |
| MUL Rd, Rs    | 010   |
| DIV Rd, Rs    | 011   |
| IN Rd         | 100   |
| OUT Rs        | 101   |

### Кодировка регистров

| Регистр | Код |
|---------|-----|
| A       | 00  |
| B       | 01  |
| C       | 10  |
| D       | 11  |

## Формат входных данных

Кодировщик получает на вход текстовые инструкции в следующем формате:

MOVI 5

ADD A, B

SUB C, D

IN A

OUT B

Правила форматирования:
- Команда пишется заглавными буквами
- После команды ставится пробел
- Регистры указываются заглавными буквами A, B, C, D
- После запятой обязательно ставится пробел

## Ограничения

- MOVI работает только с числами от 0 до 127
- Используется только 4 регистра (A, B, C, D)
- Всего 7 инструкций
- Каждая инструкция кодируется 1 байтом
- Не поддерживаются метки и переходы

## Пример работы

Вход:

MOVI 10

MOVI 5

ADD A, B

OUT A

Выход:
0x0A
0x05
0x89
0xC0

## Технологии

- Язык: C99
- Сборка: Makefile
- Тесты: интеграционные тесты в папке tests/

## Сборка и запуск

### Сборка программы

Склонируйте репозиторий и выполните сборку:

1. Скопируйте файлы проекта на свой компьютер:
   - папку src/ с исходным кодом
   - папку tests/ с тестами
   - Makefile

2. Откройте терминал в корневой папке проекта

3. Выполните команду:
   make

Готово! Программа собрана.

### Запуск программы

Интерактивный ввод:
./encoder

Вводите команды по одной на строке. Для завершения нажмите Ctrl+D (Linux/Mac) или Ctrl+Z (Windows).

Ввод из файла:
./encoder < input.txt

Сохранение вывода в файл:
./encoder < input.txt > output.hex

Очистка:
make clean
